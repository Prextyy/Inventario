🚀 EMPEZAR RÁPIDO - 3 PASOS


PASO 1: Ejecutar Actualización (IMPORTANTE)
─────────────────────────────────────────

Abre en tu navegador (como ADMIN):

    https://tu-sitio.com/inventario/upgrade-db.php

  • Inicia sesión
  • Lee los cambios propuestos
  • Click en "EJECUTAR ACTUALIZACIÓN"
  • Espera a que termine
  • Deberías ver todos "✓"


PASO 2: Verificar Instalación
──────────────────────────────

Ve a:

    https://tu-sitio.com/inventario/check-update.php

  • Debe mostrar todos los items en VERDE ✓
  • Si hay items ROJO ✗, repite Paso 1


PASO 3: ¡Usar el Nuevo Sistema!
──────────────────────────────

  📍 USUARIO: Click en "Mis Solicitudes" (menú principal)
  📍 ADMIN:   Click en "Gestionar Solicitudes" (menú principal)
  📍 ADMIN:   Agregar imágenes en "Productos" → Editar

🎯 LAS NUEVAS FUNCIONALIDADES


PARA USUARIOS
─────────────

Mis Solicitudes (nuevo menú)
├─ Tab 1: Productos Disponibles
│  └─ Grid de productos con imágenes
│     - Ver disponibilidad
│     - Solicitar cantidad
│     - Automáticamente aprobable
│
├─ Tab 2: Solicitud Personalizada
│  └─ Formulario para productos NO en inventario
│     - Nombre del producto
│     - Descripción
│     - Cantidad
│     - Requiere aprobación admin
│
└─ Tab 3: Mis Solicitudes
   └─ Historial de todas tus solicitudes
      - Estado actual (Pendiente/Aprobado/Rechazado/Entregado)
      - Fecha de solicitud
      - Notas


PARA ADMINISTRADOR
──────────────────

Gestionar Solicitudes (nuevo menú)
├─ Estadísticas en Dashboard
│  - Solicitudes Pendientes (contador)
│  - Solicitudes Personalizadas Pendientes
│  - Solicitudes Aprobadas Hoy
│
├─ Tab 1: Solicitudes de Productos
│  - Ver todas las pendientes
│  - Revisar: Producto, Área, Usuario, Cantidad, Fecha
│  - Acciones: Aprobar / Rechazar / Marcar Entregado
│
└─ Tab 2: Solicitudes Personalizadas
   - Ver solicitudes de productos nuevos
   - Mismas acciones: Aprobar / Rechazar / Marcar Completado


AGREGAR IMÁGENES A PRODUCTOS
────────────────────────────

Productos → Editar → Bajá hasta "Imagen del Producto"
├─ Ver imagen actual (o 📦 si no hay)
├─ Seleccionar archivo (JPG, PNG, GIF, WebP, máx 5MB)
└─ ¡Listo! Las imágenes aparecen en solicitudes

❓ PREGUNTAS FRECUENTES


P: ¿Debo ejecutar upgrade-db.php?
R: SÍ, es obligatorio la primera vez. Luego es seguro ejecutarlo xotras veces.


P: ¿Qué pasa si no veo "Mis Solicitudes" en el menú?
R: Recarga la página (Ctrl+F5). Si persiste, verifica check-update.php


P: ¿Puedo agregar imágenes a productos existentes?
R: Sí, ve a Productos → Editar → Imagen del Producto


P: ¿Los usuarios pueden rechazar solicitudes?
R: No, solo el ADMIN puede aprobar/rechazar solicitudes.


P: ¿Hay notificaciones por email?
R: Ahora no, pero el usuario ve el estado en "Mis Solicitudes" en tiempo real.


P: ¿Qué formatos de imagen acepta?
R: JPG, PNG, GIF, WebP. Máximo 5MB por imagen.

🆘 AYUDA RÁPIDA


"Error: Tabla no existe"
  → Ejecuta upgrade-db.php nuevamente


"No se puede subir imagen"
  → Verifica: JPG/PNG/GIF/WebP, < 5MB
  → Verifica permisos de uploads/ (755)


"Mi usuario no está asignado a área"
  → Admin debe asignarte un área en la BD
  → Próximamente habrá panel para esto


"No veo "Gestionar Solicitudes""
  → Debes estar logeado como ADMIN
  → Verifica tu rol

# Sistema de Inventario

## Archivos que se generan automáticamente

- `config.php` - Archivo de configuración (creado durante instalación)
- Archivos de sesión de PHP
- Logs del sistema

## Archivos subidos por usuarios

Los archivos subidos se almacenan en la carpeta `/uploads/`

---

**Nota:** Este archivo está aquí solo como placeholder. 
El directorio uploads/ debe tener permisos de escritura (chmod 755 o 777 dependiendo del servidor).

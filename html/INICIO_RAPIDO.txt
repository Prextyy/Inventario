┌────────────────────────────────────────────────────────────────┐
│  PASO 1: Instalar el Sistema                                 │
└────────────────────────────────────────────────────────────────┘

1. Abre tu navegador web
2. Ve a: http://tu-servidor/install/
3. Sigue el asistente (2 pasos simples)
4. ¡Listo para usar!


┌────────────────────────────────────────────────────────────────┐
│  PASO 2: Agregar Productos                                   │
└────────────────────────────────────────────────────────────────┘

1. Inicia sesión
2. Ve a "Productos" > "Nuevo Producto"
3. Llena el formulario
4. Guarda


┌────────────────────────────────────────────────────────────────┐
│  PASO 3: Usar Entrada Rápida                                 │
└────────────────────────────────────────────────────────────────┘

1. Ve a "Entrada Rápida"
2. Escanea QR o escribe código
3. Selecciona Entrada/Salida
4. Ingresa cantidad
5. Enter para registrar

┌────────────────────────────────────────────────────────────────┐
│  FLUJO DE TRABAJO DIARIO                                     │
└────────────────────────────────────────────────────────────────┘

MAÑANA:
  1. Revisar Dashboard
  2. Ver productos con stock bajo
  3. Hacer pedidos si es necesario

DURANTE EL DÍA:
  1. Usar Entrada Rápida para movimientos
  2. Registrar cada entrada/salida
  3. Agregar razones en los movimientos

FIN DE DÍA:
  1. Revisar movimientos del día
  2. Verificar stock
  3. Exportar reporte si es necesario

SEMANAL/MENSUAL:
  1. Hacer respaldo de base de datos
  2. Revisar inventario completo
  3. Exportar Excel para análisis


┌────────────────────────────────────────────────────────────────┐
│  CONFIGURAR ESCÁNER QR (Opcional)                            │
└────────────────────────────────────────────────────────────────┘

Opción Más Fácil:
  1. Abre: quick-entry.php
  2. Busca línea: <script src="assets/js/html5-qrcode.min.js">
  3. Reemplaza por:
     <script src="https://cdn.jsdelivr.net/npm/html5-qrcode@2.3.8/html5-qrcode.min.js"></script>
  4. ¡Listo!

El sistema funciona perfectamente SIN escáner QR también.


┌────────────────────────────────────────────────────────────────┐
│  SOLUCIÓN RÁPIDA DE PROBLEMAS                                │
└────────────────────────────────────────────────────────────────┘

❌ Error de conexión MySQL
   → Verifica usuario, contraseña y que MySQL esté corriendo

❌ No aparece escáner QR
   → Configura la librería (ver sección arriba)
   → Permite acceso a cámara en el navegador

❌ No puedo exportar
   → Verifica permisos de escritura en el servidor

❌ Olvidé mi contraseña
   → Accede a MySQL y cambia el hash en tabla 'users'

┌────────────────────────────────────────────────────────────────┐
│  RESPALDOS                                                   │
└────────────────────────────────────────────────────────────────┘

HACER BACKUP:
  1. Inicia sesión como admin
  2. Ve a "Respaldo"
  3. Clic en "Descargar Respaldo"
  4. Guarda el archivo .sql

RESTAURAR BACKUP:
  1. Abre phpMyAdmin
  2. Selecciona tu base de datos
  3. Pestaña "Importar"
  4. Sube el archivo .sql
  5. Clic en "Continuar"

┌─ PRIMERAS PRUEBAS ─────────────────────────────────────────────────────────┐
│                                                                             │
│  1️⃣  USUARIO - Crear una solicitud                                         │
│      • Click en "Mis Solicitudes"                                          │
│      • Elige un producto                                                   │
│      • Ingresa cantidad                                                    │
│      • Click en "Solicitar"                                                │
│      ✓ Debe decir "Solicitud creada exitosamente"                          │
│                                                                             │
│  2️⃣  ADMIN - Aprobar solicitud                                             │
│      • Click en "Gestionar Solicitudes"                                    │
│      • Verás la solicitud recién creada                                    │
│      • Click en "Aprobar"                                                  │
│      ✓ Estado debe cambiar a "Aprobado"                                    │
│                                                                             │
│  3️⃣  ADMIN - Agregar imagen a producto                                     │
│      • Click en "Productos" → Editar producto                             │
│      • Baja hasta "Imagen del Producto"                                    │
│      • Click en "Seleccionar Archivo"                                      │
│      • Elige una imagen (JPG, PNG, GIF, WebP)                             │
│      • Máximo 5MB                                                          │
│      • Click "Guardar Imagen"                                              │
│      ✓ Deberías verla actualizada                                          │
│                                                                             │
│  4️⃣  USUARIO - Ver imagen                                                  │
│      • Click en "Mis Solicitudes"                                          │
│      • Tab: "Productos Disponibles"                                        │
│      • Deberías ver las imágenes que agregaste 🖼️                          │
│      ✓ Si no hay imagen, verás 📦 placeholder                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

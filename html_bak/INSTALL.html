Pasos para la Instalación

📋 Paso 1: Preparar la Base de Datos

Antes de continuar, asegúrate de tener:

  • Una base de datos MySQL creada
  • El nombre de usuario y contraseña de MySQL
  • El nombre del host (generalmente localhost)

🚀 Paso 2: Ejecutar el Instalador

Haz clic en el botón de abajo para iniciar el asistente de instalación:

Iniciar Instalación

📷 Paso 3: Configurar Escáner QR (Opcional)

Para usar el escáner de códigos QR, necesitas la librería Html5-QRCode.

Opción Rápida: El sistema funciona sin el escáner, puedes configurarlo después.

Para configurarlo ahora: Lee el archivo assets/js/DOWNLOAD_QR_LIBRARY.md

⚠️ Importante
Elimina este archivo (INSTALL.html) después de completar la instalación por seguridad.

Características del Sistema

  • ✅ Gestión completa de productos
  • ✅ Entrada rápida con teclado
  • ✅ Escáner de códigos QR/Barras
  • ✅ Exportación a PDF y Excel
  • ✅ Control de stock bajo
  • ✅ Historial de movimientos
  • ✅ Interfaz moderna y responsive
  • ✅ Multi-usuario con roles

Requisitos del Sistema

  • PHP 7.0 o superior
  • MySQL 5.6 o superior
  • Servidor web (Apache/Nginx/IIS)
  • Navegador moderno
